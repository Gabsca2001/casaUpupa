# 🌿 Casa Upupa

Sito web ufficiale di **Casa Upupa**, una villa privata immersa nella campagna toscana, progettata per offrire un'esperienza di soggiorno esclusiva caratterizzata da natura, tranquillità, design contemporaneo e privacy.

🌐 **Website:** [www.casaupupa.com](https://www.casaupupa.com/)

## 📌 Descrizione

Il progetto consiste nella realizzazione del sito web di **Casa Upupa**, una villa situata nel cuore della Toscana, a pochi minuti da Bolgheri e dalla costa.

Il sito è stato progettato con un approccio fortemente visuale ed emozionale, con l'obiettivo di raccontare non soltanto la struttura, ma l'intera esperienza di soggiorno.

Fotografie, spazi ampi, testi essenziali e una navigazione minimalista contribuiscono a comunicare i valori principali della struttura:

- Natura
- Relax
- Privacy
- Design
- Comfort
- Territorio
- Slow living
